# Database migrations

Migrations are generated by Drizzle and immutable after review. M13 adds `0014_last_magus.sql`; prior migrations must not be edited, squashed, reset, or replaced with `db:push`.

Before production migration, create the encrypted backup checkpoint and run:

```powershell
npm run db:preflight
npm run db:migrate
```

The migrator validates runtime configuration, acquires PostgreSQL advisory lock `7130413`, runs the Drizzle chain, releases the lock, and exits non-zero on failure. Run it as the one-shot Compose `migrator` service before app/worker rollout.

Stop on connectivity, journal, lock, schema, or keyring errors. Do not use `db:push`, `DROP DATABASE`, or volume deletion. Verify the migration journal, `ai_generation_idempotency`, `workflow_run_dispatches`, readiness, and outbox recovery after success.
